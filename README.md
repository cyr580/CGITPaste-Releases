# CGITPaste Releases

Binary distribution and update metadata for CGITPaste. Source code is maintained separately.

## What is here

* `desktop-stable.json` — the stable update channel: which released Desktop package is current, what it contains, and where it and its provenance live.
* The released Windows installer it names, and that release's provenance document.

Nothing else. There is no source code in this repository and no credential of any kind: every file here is readable without authentication, which is what lets the product check for an update without being told who it is.

Each package is built, validated and approved before it is published here, and the manifest is only written once the package it names has been verified.
